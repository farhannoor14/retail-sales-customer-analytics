# Retail Sales & Customer Analytics

An end-to-end Data Analyst portfolio project focused on analyzing transactional retail data and turning it into actionable business insights.

## Live Dashboard

**[Open Interactive Dashboard](https://farhannoor14.github.io/retail-sales-customer-analytics/dashboard/)**

## Project Overview

This project analyzes retail sales and customer data to understand business performance across categories, cities, products, customers, and time periods.

The analysis includes data validation, data cleaning, exploratory analysis, KPI analysis, customer analysis, SQL-based queries, Python analysis, and interactive dashboard reporting.

## Business Questions

- Which categories and cities generate the most revenue?
- Which products contribute most to profit?
- How do discounts affect sales and profitability?
- Which customers are high-value and how concentrated is revenue?
- What trends can be identified from sales performance?

## Tools & Technologies

**Python, Pandas, NumPy, SQL, MySQL, Excel, Power BI, Tableau, Power Query, DAX, Data Visualization, Exploratory Data Analysis (EDA)**

## Project Workflow

1. Data collection and validation
2. Data cleaning and quality checks
3. Exploratory data analysis
4. KPI and customer analysis
5. SQL-based business analysis
6. Dashboard development
7. Business insights and reporting

## Dataset

The project uses a **synthetic retail dataset** created for portfolio and interview demonstration purposes.

The dataset contains:

- 40 orders
- 18 customers
- 6 cities
- 5 product categories
- Product, quantity, price, discount, sales, and profit information
